# PiLink documentation

This directory contains maintained product and operational documentation.

## Maintained documents

- [`GETTING_STARTED.md`](GETTING_STARTED.md) — installation, configuration, and first-time setup.
- [`THREAT_MODEL.md`](THREAT_MODEL.md) — security boundaries, capabilities, and accepted risks.
- [`RELEASING.md`](RELEASING.md) — npm release procedure.

The repository source code, tests, schemas, root `README.md`, and current configuration examples remain authoritative when documentation becomes stale.

## Local agent artifacts

Agent-generated research reports, temporary planning documents, design drafts, and revision-specific acceptance reviews are intentionally excluded from the product repository through `.gitignore`. Durable product behavior should be represented by implementation, tests, concise maintained documentation, issues, or pull-request history rather than large local coordination transcripts.

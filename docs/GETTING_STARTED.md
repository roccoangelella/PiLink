# Getting started

This filename is retained for links from older releases. The onboarding flow
has been consolidated so it cannot drift across several documents.

1. Follow [Installation](INSTALLATION.md).
2. Follow [Connect ChatGPT Work](CONNECT_CHATGPT.md).
3. Begin with the read-only first task in that guide.
4. Read [Usage, models, and costs](USAGE_AND_COSTS.md) before selecting an
   OpenAI or Pi Local model.
5. Read [Security model](SECURITY_MODEL.md) before enabling repository
   execution or Full access.

Current official ChatGPT web support places plugins and remote MCP-backed tools
in **Work**, not normal Chat. Legacy Developer Mode/custom-connector screens
are compatibility-only and may vary by account. When DCR is available, there
is no callback URL or client secret for the user to copy.

For errors, use the layer-by-layer
[Troubleshooting guide](TROUBLESHOOTING.md).
